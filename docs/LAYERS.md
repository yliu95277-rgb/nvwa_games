# 图层操作说明

图层是有序容器，元素是放在其中的图片或文字。选择“建筑”层时，下面只列本层建筑；不会把每张 PNG 都当成一个图层。

## 主城默认分层

| 层 | 数量 | 内容 |
|---|---:|---|
| 背景 | 1 | 地形与远景底板 |
| 建筑 | 5 | 城主府、招贤馆、兵营、集市、铁匠铺 |
| 角色 | 9 | 士兵、瞭望角色与前景护栏 |
| 旗帜 | 9 | 独立旗帜素材 |
| 界面 | 14 | 头像、资源、工具入口、5个独立导航、底栏背景、出征 |

共38个元素。底栏背景和5个导航按钮分别可选；远景墙体仍在背景内，不声称全部场景都已拆分。

## 常用操作

1. 点击图层名切换当前层。默认“隔离编辑当前层”关闭，可点击任意元素并自动切换到其图层；开启后画布拖动只作用于当前层，减少重叠误选。
2. 用眼睛按钮隐藏整层，用锁按钮锁定整层；元素也有各自的显隐/锁定。父节点隐藏或锁定会影响后代。
3. ＋新增层，重命名修改标签，↑/↓改变图层绘制顺序。元素列表和检查器负责层内元素顺序。
4. 选元素后在“所属图层”中迁移；其子树一起迁移。parentId 用于局部坐标变换，是另一项关系。
5. 删除图层会删除其中元素及后代，跨层子节点也会受影响；操作有确认并可撤销。最后一个图层不能删除。
6. 导入图片进入当前层。导出 JSON 带图层和图片；保存到浏览器使用 IndexedDB。

## 旧文档

没有 layers 的旧文档自动补层。旧主城合并底栏 Art_hud-bottom 需连接本地主城服务拆成六个新元素；迁移后重新导出自包含 JSON，便可独立使用。通用编辑器可创建任意层，但应用到主城仍受现有 Sprite ID 和适配范围约束，需重编译后生效。

## 多选、对齐与分布

在画布或元素列表使用 Shift/Ctrl 点击添加或移除所选元素；仍遵循当前层隔离和锁定限制。工具栏的“已选”计数用于确认批量操作范围。

对齐参照可选“相对画布”或“相对所选范围”。左/右/顶/底对齐作用于边缘；水平/垂直居中作用于相应中心。“整体居中”同时使用水平与垂直方向。使用前确认参照范围，避免把原本有间距的按钮叠到同一中心。

水平/垂直等距用于多个元素的排布；建议至少选择三个元素，并先检查端点和尺寸。旋转、缩放与父子局部坐标的具体计算以当前数据核心实现为准。对齐后可撤销，并应在主城适配构建中核对视觉和点击热区。

## 多界面与参考图操作

顶部“界面”条可新增、复制、重命名、删除和切换。至少保留一个界面。每界面的图层、元素、素材与参考图独立；切换保留内存编辑结果，但清空撤销历史。请点击“保存到浏览器”持久化完整工作区；没有自动保存。

右侧“设计参考”上传或移除当前界面参考图，支持15MB以内PNG/JPG/WebP/GIF。点击预览弹出大图；顶部参考图开关和右侧0–100透明度滑块用于画布叠加。网格/中心线不拦截输入，控制手柄位于可操作叠加层。

默认隔离编辑关闭，点击任意可编辑元素会自动选择所在图层。需要专注建筑或旗帜时再开启“隔离编辑当前层”。多选时仍需注意锁定及有效父级状态。

“导出JSON”只带当前布局素材；要连同所有界面和参考图迁移，使用“导出界面集”。通用多界面不等于自动创建Cocos场景，写回限制保持不变。
