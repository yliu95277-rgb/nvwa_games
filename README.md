# 城构 · 游戏界面布局编辑器

独立的中文浏览器图形编辑工具，用于摆放图片、调整图层与导出布局 JSON。界面、布局数据模型与 Cocos 写回桥分离；编辑器本身不依赖 Cocos 或 npm 第三方包。当前随附三国主城适配器。

## 本地启动

需要 Node.js 22+，在本目录执行：

```sh
npm start
```

打开 `http://127.0.0.1:8820`。服务只监听本机地址；请使用此精确地址，localhost 别名不在当前 Host 白名单。主城素材读取自同级 `../three-kingdoms-city`。本项目使用本地 Git 管理，未配置或发布在线托管。

```sh
npm test
```

该命令运行布局模型测试，非浏览器视觉验收。浏览器交互证据另由交付记录说明。

## 使用

1. 打开主城示例，或导入版本 1 布局 JSON。
2. 先选择左侧图层，再在该层元素列表或画布选择对象，拖动移动；使用角落手柄调整宽高、上方手柄旋转。Shift 调整宽高时保持比例；Shift 旋转吸附到 15°。网格是视觉辅助，吸附按 5 单位生效，Alt 拖动暂时绕过。
3. 右侧修改位置、尺寸、缩放、角度、锚点、透明度、父节点和层级；可隐藏、锁定、复制、删除。列表支持拖动排序。
4. 素材页导入 PNG/JPG/WebP/GIF，图片加入素材库并创建对象。点击已有素材可重复放入。文字节点可通过 JSON 创建并在检查器编辑；当前没有专门的新增文字按钮。
5. 撤销/重做按钮或 Ctrl/Cmd+Z、Ctrl/Cmd+Y；Shift+Ctrl/Cmd+Z 重做。Ctrl/Cmd+D 复制，Delete 删除；方向键移动 1 单位，Shift+方向键移动 10 单位。
6. 保存到浏览器写入 IndexedDB（旧 localStorage 文档可回退读取）；导出 JSON 会将可读取图片打包成 data URL，适合跨电脑与独立静态部署。

## 应用到主城

“应用到主城”通过本机服务写入固定的 `../three-kingdoms-city/assets/resources/layouts/city-layout.json`，并保存编辑器目录的 `city-project.json`。需要重新编译主城后才生效，**不是编辑器中实时控制 Cocos 节点**。

该适配器只接受 1672×941、已支持的主城 Sprite ID、根级父节点。编辑器支持的任意新增图片/层级不等于主城桥全部支持。详细映射与限制见 [Cocos 适配说明](docs/cocos-adapter.md)。

## 范围与限制

当前单选，支持图片与基础文字节点；不执行任意导入脚本，也不导入任意 SVG、引擎场景、动画或 Prefab。图片资源大小、跨域读取与浏览器存储配额会限制大工程。父子变换支持层级编辑，但改变父节点会按新的父空间解释坐标，不承诺保留世界位置。此工具是可复用的 2D 布局编辑器，不是完整游戏引擎编辑器。

更多 schema、静态部署和二次接入方式见 [可移植性说明](docs/PORTABILITY.md)。

## 显式图层与当前主城素材

布局新增 layers[] 与 node.layerId，区分图层容器和层内元素。支持图层新增、重命名、删除、排序、显隐和锁定；按需开启“隔离编辑当前层”，便于隔离重叠素材。操作见 [图层说明](docs/LAYERS.md)。

当前完整默认主城为 5 层、38 个元素：背景 1、建筑 5、角色 9（含前景护栏）、旗帜 9、界面 14。底部 5 个导航按钮已独立，背景板另算 1 个界面元素；旗帜是独立资源而非底板上的移动假象。背景层仍有烘焙远景和城墙，不是全部环境拆层。

旧版无 layers 的文档会补默认层（可识别主城时按语义归类）。旧主城 Art_hud-bottom 合并底栏需要连接本地主城服务迁移为 5 个导航按钮加 1 个底栏背景；迁移完成后再导出，供独立部署使用。新图层功能的浏览器与 Cocos 最终回归证据以最新验收记录为准。

### 对齐
选中元素后使用画布上方对齐工具。Shift/Ctrl 点击元素列表或画布可多选；切换“相对画布 / 相对所选范围”。三个以上可等距分布；锁定/隐藏项不参与，操作可撤销。

## 多界面工作区与参考图

顶部缩略图条管理多个独立界面：新增、复制、重命名、删除与切换。每个界面各有布局文档、素材、图层及一张可替换参考图。切换前修改保留在内存，切换后撤销历史重新开始；只有点击“保存到浏览器”才持久化，当前没有自动保存。

- “导出 JSON”导出当前布局与内嵌素材，不含工作区参考图。
- “导出界面集”导出全部界面、素材与参考图，可在另一台电脑导入继续编辑。
- 导入支持普通布局 JSON 和 kind=layout-workspace 的界面集。
- 右侧可上传15MB以内 PNG/JPG/WebP/GIF 参考图，点击缩略图放大；顶部“参考图”开关叠加到画布，透明度0–100%。
- 网格与画布中心线为不拦截输入的辅助叠加，选中元素的控制手柄保持可操作。

默认不开启隔离编辑：点击任意元素会切换其所在图层。按需勾选“隔离编辑当前层”才限制画布编辑范围。

多界面是编辑器工作区能力；当前 Cocos 桥仍只支持“当前主城布局”的既有元素，不代表游戏已实现这些新界面或自动生成多场景。
